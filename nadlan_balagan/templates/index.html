What can I search?

Create one .toml file per search in the project's searches/ folder. Copy gush_30303.toml, give the copy a unique id and a descriptive title, then set its filters. The files are read before each run; there is no need to restart the app after editing them.

  • Location: a range of gush (block) numbers. Use the same number for from and to to search one gush.
  • Property and transaction: use the site's Hebrew dropdown labels, such as דירת מגורים and הכל. Transaction choices depend on the property type; a label the site does not offer causes a clear search error.
  • Period: the last 3, 6, 12, or 36 months. These are rolling windows calculated by the site when each search runs.
  • Multiple searches: add more files; enabled searches run one by one each day at 08:00 UTC. Set enabled = false to keep a search without running it.
Example search file 
id = "gush-30303"
title = "Apartments in gush 30303"
enabled = true

[location]
kind = "gush_range"
from = 30303
to = 30303

[filters]
property_type = "דירת מגורים"
transaction_type = "הכל"
period = "last_12_months"

Available period values: last_3_months, last_6_months, last_12_months, last_36_months. City autocomplete, individual parcel searches, and custom date ranges are not supported yet. Searches are configured in files, not in this page.
